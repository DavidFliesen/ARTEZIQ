# ARTEZIQ Website

GitHub Pages website for `arteziq.com`.

## Publishing

Upload everything in this folder to the root of the `ARTEZIQ` repository. In **Settings → Pages**, publish from the `main` branch and `/(root)`. Keep the `CNAME` file containing `arteziq.com`.

The homepage assets in `assets/home/` were exported directly from the supplied layered Photoshop file. The former bottom gold-to-gray curved element has been removed.
