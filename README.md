# ARTEZIQ Website

Responsive single-page static website for ARTEZIQ.

## Files
- `index.html` — site structure and content
- `styles.css` — responsive visual design
- `script.js` — navigation, scroll effects, and current year
- `assets/` — supplied ARTEZIQ graphics

## Publish on GitHub Pages
1. Create a new repository.
2. Upload all files and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/root`, then save.

No build process is required.
